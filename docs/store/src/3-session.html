Local only

The extension talks to a hub on 127.0.0.1 and nothing else. No analytics, no telemetry, no account.

A web page cannot drive it

The hub needs a token from your disk and refuses requests that come from a browser page.

No code injected on demand

Only the scripts in the package run, with a fixed set of operations: read, fill, click, select, wait.

Its own window, one tab per session

Beam works in a window that stays in the background, and refuses to write if you moved its tab elsewhere.
