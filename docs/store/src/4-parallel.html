BeamChrome control for CLI agents

Parallel agents, separate windows.

Each session name gets its own window and tab. beam network shows what a click calls.

Two agents at onceBEAM_SESSION
$ BEAM_SESSION=catalog beam open http://127.0.0.1:8791/wp-admin/post.html
$ BEAM_SESSION=orders  beam open https://example.com/
$ beam sessions
* catalog  [1197221790]  Edit product · Northwind Shop
      http://127.0.0.1:8791/wp-admin/post.html
  orders  [1197221795]  Example Domain
      https://example.com/
