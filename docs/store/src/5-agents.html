BeamChrome control for CLI agents

Built for Claude Code. Plain Node for everything else.

Install the plugin and Claude gets the CLI and two skills. Any agent with a shell can use the same commands.

Claude Codeplugin
$ claude plugin marketplace add darksns/beam
✔ Successfully added marketplace: beam

$ claude plugin install beam-chrome@beam
✔ Successfully installed plugin: beam-chrome@beam
